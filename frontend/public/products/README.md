# Images produits

Dépose ici tes images de produits (format recommandé : carré, 800x800px min, .jpg ou .webp).

Puis, dans l'admin (Ajouter/Modifier un produit), renseigne le champ "URL de l'image" avec :

/products/nom-de-ton-fichier.jpg

Exemple : si tu ajoutes `products/creme-hydratante.jpg`, mets `/products/creme-hydratante.jpg`
dans le formulaire produit.

Si aucune image n'est fournie, un placeholder visuel s'affiche automatiquement (aucun écran cassé).
